# 🌅 Evl Browser

✦ 

<details>
<summary><b>Compilar e gerar o instalador</b></summary>

```text
npm install
npm start          # roda o navegador
npm test           # testes
npm run dist:win   # instalador + versão portátil para Windows em dist/
npm run dist:linux # AppImage para Linux em dist/
```

</details>

<details>
<summary><b>Atalhos</b></summary>

| Atalho | Ação |
|---|---|
| Ctrl+T | Nova aba |
| Ctrl+W | Fechar aba |
| Ctrl+L | Focar a barra de endereço |
| Ctrl+R | Recarregar |
| Ctrl++ / Ctrl+- | Aumentar / diminuir o zoom (também Ctrl + roda do mouse) |
| Ctrl+0 | Zoom em 100% |
| Ctrl+D | Adicionar aos favoritos |
| Ctrl+F | Localizar na página (Enter / Shift+Enter andam entre os resultados, Esc fecha) |
| Ctrl+G / Ctrl+Shift+G | Próximo / anterior resultado da busca |
| Ctrl+, | Configurações |
| Ctrl+H | Histórico |
| Ctrl+J | Downloads |
| Ctrl+Shift+T | Reabrir a última aba fechada |
| Ctrl+Shift+P | Vídeo da página em picture-in-picture |
| Ctrl+I | Permissões deste site |
| Ctrl+Shift+Y | Traduzir esta página |
| Ctrl+Shift+I | DevTools da aba ativa |
| F12 | DevTools da interface do navegador |

</details>

<details>
<summary><b>Por que usar Evl Browser?</b></summary>

Evl é um navegador feito pela comunidade, de código aberto: qualquer pessoa pode ajudar, auditar ou melhorar.

- Navegação segura: cada aba roda isolada e não consegue ler os dados de outras abas
- Navegação Rapida:
- Muito personalizável.

</details>
