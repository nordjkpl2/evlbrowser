# Evl Browser

✦ Web-browser made using electron , html , css and javascript with focus in using lower ram
firefox style running in chromium and NS Nord Suite Engine(s)

<details>
<summary><b>/Build</b></summary>

```text
npm install
npm start
npm test
```

</details>

<details>
<summary><b>/Shortcuts Keybinds</b></summary>

## Atalhos

| Atalho | Ação |
|---|---|
| Ctrl+T | Nova aba |
| Ctrl+W | Fechar aba |
| Ctrl+L | Focar a barra de endereço |
| Ctrl+R | Recarregar |
| Ctrl++ / Ctrl+- | Aumentar / diminuir o zoom (também Ctrl + roda do mouse) |
| Ctrl+0 | Zoom em 100% |
| Ctrl+, | Configurações |
| Ctrl+H | Histórico |
| Ctrl+J | Downloads |
| Ctrl+Shift+T | Reabrir a última aba fechada |
| Ctrl+Shift+I | DevTools da aba ativa |
| F12 | DevTools da interface do navegador 

</details>
